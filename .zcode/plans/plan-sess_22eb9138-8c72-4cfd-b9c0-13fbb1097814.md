# Shell 预览改为单栏推入式（阅读取代流）

## Context

Shell 预览（`SHU_WINDOW=shell`，`app/shell.go`）目前虽无侧边栏，但中部仍是左右分栏：流列（`MaxWidth(720)` 居中）+ 固定 620 宽的阅读栏，中间一根 1px 分隔线（`shell.go:203-217`）。`shell.go:20-22` 的注释早已写明意图（"Reading opens over the stream as a sheet rather than beside it"）但代码没做到。本次把它改成单栏：窗口永远只做一件事——要么在扫（流），要么在读（会话顶上来占据同一列），Esc/返回弹出回列表。侧栏窗口（默认）完全不动；roadmap 的「迁移测试并设为默认」是后续独立一步。

## 设计

- **同一个列，两个状态**：中列仍 `MaxWidth(720)` 居中。列表态 = `shellHead` + `listBody`；阅读态 = `readingPane`（共享函数，会话/单消息/HTML 全部复用）。两个子树各自 key（`stream-list` / `stream-reading`）+ `Transition(readingMotion)`（已有的 160ms 淡入）。
- **状态模型：选中即打开**。shell 自有字段 `a.readingOpen bool`（与 `palette` 相邻声明在 app 结构体），由两个自守卫的 shell 方法开关：
  - `openReading()`：`shellWindow()` 且选中有效时置 true
  - `shellBack()`：`closeReading()` + `clearSelection()`（已有的 app.go:985）
- **共享代码里的挂钩（每处一行，自守卫）**：
  - 打开：`messagelist.go` OnChange（点击行）、`reading.go` `stepMessage`（J/K）、`drafts.go` `openSelected`（Enter 在非草稿上打开——shell 没有旁边的栏了）→ 调 `a.openReading()`
  - 关闭（归档/删除所读内容即返回列表）：`conversations.go` `moveThreads`（:854 已置 `a.conv=nil` 处）和 `reading.go` `moveSelected` 非会话分支（:694 附近）→ 调 `a.closeReading()`。避免选中被钳到下一行后卡在永久 spinner
  - 绘制守卫 `readingOpen && selected 在 a.all 界内`：换文件夹/行被移走时自动落回列表，安全网
- **返回入口两处**：工具栏最左加返回按钮（`bar.go` `readingBar` 的 actions 行首，`shellWindow()` 时才画；`chevron-left.svg` 已在 icons/），Escape 快捷键（shellView 注册；palette/Modal 打开时它们的 Escape 先消费）。locale 新增 `BackToStream`（en + zh-Hans 同步）。
- **窗口最小尺寸**：`run.go:111-124` 在 `shellWindow()` 时把 Min 尺寸降到 720×520（回应单栏后不再需要 1000 宽的协商；默认窗口不受影响）。

## 测试（新 `app/shell_test.go`）

helper：`startSample` + `t.Setenv("SHU_WINDOW","shell")` + `ui.NewTester(a.view, 1000, 640)`。用例：

1. 初始显示流；点击行 → 会话内容出现、流行消失；Esc → 回列表；再点同一行能再次打开（Esc 已清选中）
2. 返回按钮（chevron-left，按 locale 文案找）与 Esc 等效
3. J/K 打开所步进的行；Enter 打开高亮行
4. 阅读态按归档（toolbar 归档按钮）→ 回到流且该行已消失
5. 阅读态 Cmd+K 开 palette → Esc 只关 palette 仍在阅读 → 再 Esc 回流；palette 里换文件夹 → 回列表
6. 几何：列表态与阅读态共用同一列边界（1000×640 与 1220×800，light+dark 各一轮，照 `searchview_test.go:407` 模式）
